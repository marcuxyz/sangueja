# 🩸 SangueJá

> **Conectando doadores a quem mais precisa, através da tecnologia.**

O **SangueJá** é uma plataforma **open source** que monitora informações públicas dos hemocentros brasileiros e ajuda a aproximar doadores das campanhas de doação de sangue.

Nosso objetivo é simples:

> **Salvar vidas facilitando o acesso à informação.**

---

## ❤️ Nossa missão

Todos os dias, hemocentros divulgam a necessidade urgente de determinados tipos sanguíneos.

Essas informações, muitas vezes, ficam espalhadas em diferentes sites e redes sociais.

O **SangueJá** nasceu para reunir essas informações em um único lugar e notificar doadores quando sua ajuda realmente puder fazer a diferença.

# ❤️ Open Source

Este projeto é desenvolvido de forma aberta.

Queremos que desenvolvedores de todo o Brasil possam contribuir adicionando novos hemocentros, melhorias na plataforma e novas funcionalidades.

Toda contribuição é bem-vinda.

---

# 🎯 Objetivo

O SangueJá não pretende substituir os hemocentros.

Nosso propósito é ampliar o alcance das campanhas de doação, facilitar o acesso às informações públicas e incentivar cada vez mais pessoas a doar sangue.

---
